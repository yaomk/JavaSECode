## 方法引用（Method Reference）

方法引用（Method Reference） 是 `Java 8` 引入的语法糖，用于简化 `Lambda` 表达式。当 `Lambda`
体只是调用一个已经存在的方法时，可以用方法引用替代，使代码更简洁。

### 基本语法

| 类型                     | 语法             | 	等价 Lambda                       | 	说明                     |
|:-------------------------|:-----------------|:----------------------------------|:-------------------------|
| 静态方法引用             | 	类名 :: 静态方法 | 	(args) -> 类名.静态方法(args)     | 引用类的静态方法         |
| 实例方法引用（特定对象） | 	对象 :: 实例方法 | 	(args) -> 对象.实例方法(args)     | 	引用某个具体对象的方法   |
| 实例方法引用（任意对象） | 	类名 :: 实例方法 | 	(obj, args) -> obj.实例方法(args) | 	第一个参数作为方法调用者 |
| 构造器引用               | 	类名 :: new      | 	(args) -> new 类名(args)          | 	引用构造方法             |
| 数组构造器引用           | 	数组名 :: new    | 	(len) -> new 数组名[len]          | 	引用构造方法             |

* 使用双冒号 `::` 分隔类名（或对象名）与方法名。
* 没有参数列表和括号，参数由编译器根据上下文自动推断。
* 方法引用本身不是方法调用，它只是对方法的引用，需要赋值给函数式接口。“万事万物皆对象”。

### 方法引用的使用条件

方法引用能替代 Lambda 的前提是：

* Lambda 体 **只有一行代码**，且这一行是 **直接调用某个已有方法**（或构造器）。
* 被引用方法的 **参数列表和返回值类型**必须与函数式接口的抽象方法 **兼容**。

```
// ✅ 可以用方法引用
list.forEach(s -> System.out.println(s));
list.forEach(System.out::println);

// ❌ 不能直接用方法引用（Lambda 体有额外逻辑）
list.forEach(s -> System.out.println(s.toUpperCase()));
// 无法写成方法引用，因为涉及 toUpperCase 和 println 两步
```

### 方法引用使用的注意事项

* 歧义问题：当存在重载方法时，编译器会根据函数式接口的签名自动选择最匹配的方法。

```
// 假设有多个重载的 println 方法
list.forEach(System.out::println); // 编译器自动匹配
```

* 不能引用私有方法（除非在同一个类中通过 this::method 引用）。

* 实例方法引用中，第一个参数作为调用者，这是最容易混淆的地方：

```
// String::compareTo 等价于 (s1, s2) -> s1.compareTo(s2)
Comparator<String> c = String::compareTo;
```

* **方法引用不能有额外逻辑**，如果需要在调用前后做其他操作，只能用 Lambda。

### 示例

* 静态方法引用

```
// 语法
String::valueOf
Math::round
Integer::compare

// Lambda
Function<Integer, String> f1 = i -> String.valueOf(i);
// 方法引用
Function<Integer, String> f2 = String::valueOf;
// 多参数示例
Comparator<Integer> comp1 = (a,b) -> Integer.compare(a,b);
Comparator<Integer> comp2 = Integer::compare;
```

* 实例方法引用

```
// 语法：
// 对象 :: 实例方法
System.out::println
emp::getName

// Lambda
Consumer<String> con1 = () -> System.out.println("hello");
// 方法引用
Consumer<String> con2 = System.out::println;

// 额外的示例
Employee emp = new Employee("Jack", 11);

Supplier<String> sup1 = () -> emp.getName();
Supplier<String> sup2 = emp::getName;


// 语法：
// 类名 :: 实例方法
String::length

// Lambda
Function<String, Integer> f1 = s -> s.length();
// 方法引用
Function<String, Integer> f2 = String::length;

// 多参示例
Comparator<String> comp1 = (o1, o2) -> o1.compareTo(o2);
Comparator<String> comp2 = String::compareTo;
```

* 构造器引用

```
// 语法
ArrayList::new
Employee::new

// Lambda
Supplier<ArrayList<String>> s1 = () -> new ArrayList<>();
// 方法引用
Supplier<ArrayList<String>> s2 = ArrayList::new;
// 带参数的构造器
Function<String, StringBuilder> f1 = s -> new StringBuilder(s);
Function<String, StringBuilder> f2 = StringBuilder::new;
// 多参数的构造器
BiFunction<Integer, String, Employee> bif1 = (id, name) -> new Employee(id, name);
BiFunction<Integer, String, Employee> bif2 = Employee::new;
```

* 数组构造器引用

```
// 语法
int[]::new
String[]::new

// 方法引用
Function<Integer, int[]> creator = int[]::new;
// 等价 Lambda
Function<Integer, int[]> creator2 = length -> new int[length];
```
