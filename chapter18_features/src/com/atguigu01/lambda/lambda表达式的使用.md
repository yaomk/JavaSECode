## lambda 表达式的使用

### lambda 表达式的使用示例：

`(o1, o2) -> Integer.compare(o1, o2)`

### lambda 表达式的格式：

* `->` 的左边：lambda 形参列表，对应着要重写的接口中的抽象方法的形参列表。
* `->` 的右边：lambda 体，对应着接口的实现类要重写的方法的方法体。

### lambda 表达式的本质

* 一方面，lambda 表达式作为接口的实现类的对象。 --> “万事万物皆对象”
* 另一方面，lambda 表达式是一个匿名函数。

### 函数式接口：

#### 什么是函数式接口？为什么需要函数式接口？

* 如果接口中只声明有一个抽象方式，那么该接口就成为函数式接口。
* 因为只有给函数式接口提供实现类的对象时，我们才可以使用 lambda 表达式。

#### api 中函数式接口所在的包

jdk8 中声明的函数式接口都在 java.util.function 包下。

* 四大核心函数式接口

|   函数式接口    |    称谓    | 参数类型 | 用途                                                                                 |
|:---------------:|:----------:|:--------:|:-------------------------------------------------------------------------------------|
|  `Consumer<T>`  | 消费性接口 |    T     | 对类型 `T` 的对象应用操作，包含方法：`void accept(T t)`                              |
| ` Supplier<T>`  | 供给型接口 |    无    | 返回类型为`T`的对象，包含方法:`T get()`                                              |
| `Function<T,R>` | 函数型接口 |    T     | 对类型为`T`的对象应用操作，并返回结果。结果是`R类型`的对象。包含方法: `R apply(T t)` |
| `Predicate<T>`  | 判断型接口 |    T     | 确定类型为`T`的对象是否满足某约束，并返回`boolean`值。包含方法: `boolean test(T t)`  |

### lambda 表达式的语法规则总结

* -> 的左边：lambda 形参列表，参数的类型都可以省略。如果形参只有一个，则一对 `()` 也可以省略。
* -> 的右边：lambda 体，对应着重写的方法的方法体，如果方法只有一行执行语句，则一对 `{}` 可以省略。如果有 `return`
  关键字，则必须一并省略。
